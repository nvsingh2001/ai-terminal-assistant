# Code Editing Skill

## Overview
Searches, edits, and verifies syntax of code files.

## Parameters
- `action` (string, required): Operation type: 'search', 'edit', 'check_syntax'.
- `path` (string, required): Path to code file or directory.
- `target` (string, optional): Search query or code block to replace.
- `replacement` (string, optional): New code block.
